## Boundaries of this validation

No API-key-backed vendor endpoint was exercised directly. The official Codex CLI completed two real synthetic review stages through its existing account authentication and a subsequent public-CLI fixture scan with two selected finding assessments. That establishes the recorded transport/schema path for the inspected installation, not model security accuracy or universal subscription/model access. Claude authentication remained incomplete after its official browser login flow timed out; Grok was blocked by extension preflight before inference. Mocked and local-transport tests do not establish live compatibility for either provider. See [provider research and actual outcomes](CLI_PROVIDER_RESEARCH.md).

Eight real public agent/MCP repositories were scanned at pinned revisions and their reports are published alongside fixture examples. No user-private production deployment was supplied, and no upstream target code was executed. No AgentDojo, InjecAgent, ASB or MCPSecBench behavioral benchmark was installed or executed. No real MCP service was probed, no dependency CVE feed was queried, and no exploitability, prompt-injection resistance or production control effectiveness was established. Competitor source-pattern observations and the separate partial-metadata scan do not establish those properties.

Podman acquisition is covered by controlled subprocess tests; a live Podman engine was not exercised. Actual Docker CI uses deliberately small built fixtures, not a representative production-image corpus. Compiled application logic, runtime deployment overrides, signature trust and dependency CVEs remain unassessed even when an image scan exits 0.

SARIF passed the pinned JSON Schema check; this does not establish every semantic SARIF requirement or integration with every consumer. The static rules deliberately provide limited coverage and can have false positives and false negatives. Zero findings in the small comparison fixture or the scanner's own sources does not establish security.
